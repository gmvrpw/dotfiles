# mise

[English](README.md) | Русский

Глобальные версии инструментов: тулчейны языков (Node.js, Go, Rust, Flutter вместе с Dart),
jsvu, а также LSP-серверы и форматтеры для [nvim](../nvim/README.ru.md). Инструменты ставятся из
своих экосистем (npm, модули Go, rustup, conda-forge, PyPI, релизы на GitHub) и доступны и в
nvim, и в оболочке.

У нескольких npm-серверов меньше скачиваний в неделю, чем порог безопасности mise; они
разрешены явно через `allow_low_downloads` после проверки, что это те самые пакеты из
документации nvim-lspconfig.

## Зависимости

```sh
sudo pacman -S mise
```

Версии указаны как `latest` (у Rust — `stable`), поэтому каждый инструмент следует за
последним стабильным релизом, а не за версией, закреплённой в каком-то проекте.

После `stow mise` поставь инструменты из конфига:

```sh
mise install
```

`latest` означает последнюю *установленную* версию, поэтому `mise install` ничего не обновляет.
Чтобы перейти на свежие релизы:

```sh
mise upgrade
```

## Версии для проектов

Проект может закрепить свои версии; внутри его папки они перекрывают глобальные.

```sh
cd <проект>
mise use flutter@3.41.9                         # создаёт mise.toml (коммитится)
mise use --path mise.local.toml flutter@3.41.9  # только для себя, не коммитится
mise current                                    # какие версии действуют здесь
```

Файлы версий других менеджеров читаются для Node.js (`.nvmrc`, `.node-version`), Go
(`.go-version`), Rust (`rust-toolchain.toml`) и Java (`.java-version`, `.sdkmanrc`). У Flutter
таких файлов, которые читает mise, нет (`.fvmrc` тоже), поэтому ему нужен `mise.toml`. Python
остаётся системным и с uv.
